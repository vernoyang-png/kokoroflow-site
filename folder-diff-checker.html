What this compares

Every file's relative path, name, and size inside each folder is read directly by your browser. Files are matched by their relative path within each folder, then compared on file size to flag likely differences. This is a comparison report only — it does not read file contents byte-by-byte, and it never copies, moves, deletes, or synchronizes anything between the two folders.

Privacy

  • Storage: Nothing is saved after you leave the page.
  • Limits: Folders with tens of thousands of files may take a few seconds to list.

Frequently asked questions

Can this tool sync or merge the two folders for me?
No — by design, this tool only produces a report of differences. Browsers don't allow a webpage to write, copy, or delete files on your computer without your explicit action in a native file dialog, so any actual copying or merging needs to be done manually using your operating system's file manager.

Why does it compare file size instead of exact content?
Reading and hashing the full contents of every file in two large folders directly in a browser can be slow, especially for large media files. Comparing size is a fast, reliable first check — if you need byte-for-byte certainty on a specific file, you can always open both copies directly to confirm.

Does the folder structure (subfolders) matter?
Yes — files are matched by their full relative path, so a file in the same subfolder location in both A and B will be correctly matched, even if there are many nested folders.
