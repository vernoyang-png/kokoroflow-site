Windows 10 ESU: how to keep getting security updates

Your Windows 10 PC can stay protected until October 12, 2027. Here is how to enroll, including the free option.

Reviewed: October 2026 · Written by a computer technician with nearly 30 years of repair experience

Short answer: If your PC can't run Windows 11, enroll in Windows 10 Extended Security Updates (ESU). It keeps security fixes coming until October 12, 2027. There is a free option. Go to Settings → Update & Security → Windows Update → Enroll now.

What ESU is, and what it isn't

Microsoft ended regular Windows 10 support on October 14, 2025. ESU is a paid-or-free bridge that keeps delivering critical and important security updates for home users.

  • Included: security fixes that protect against known threats.
  • Not included: new features, other kinds of fixes, or technical support from Microsoft.

According to Microsoft, you can enroll any time until the program ends on October 12, 2027.

Three ways to enroll

One ESU license can cover up to 10 PCs. Options and timing may differ by region, for example in the European Economic Area.

Before you start: check eligibility

  • Your PC runs Windows 10, version 22H2 (Home, Pro, Pro Education or Workstations). To check, press Windows key + R, type winver, and press Enter.
  • The latest Windows updates are installed.
  • You sign in with a Microsoft account that is an administrator on the PC. A child account can't enroll.
  • Work or school PCs managed by an organization usually can't use the consumer program.

How to enroll, step by step

  1. Click Start → Settings → Update & Security → Windows Update.
  2. Click Check for updates and install everything offered. Restart if asked.
  3. Look for the Windows 10 support message and click Enroll now.
  4. If you use a local account, Windows will ask you to sign in with a Microsoft account.
  5. Choose one of the three options above and follow the prompts.
  6. When finished, Windows Update should confirm that the PC is enrolled.

If you don't see Enroll now, the usual causes are a missing update, an older Windows 10 version, or not being signed in as an administrator.

A technician's advice: use the extra year wisely

ESU buys time; it doesn't make an old PC new. Use the year to decide calmly:

  • Check whether the PC can run Windows 11. Sometimes it only needs TPM switched on. See how to check if your PC can run Windows 11.
  • Back up your photos and documents now, whatever you plan to do next.
  • Watch for scams. ESU is enrolled inside Windows Settings. Microsoft will not call you to sell it, and you never need to give a stranger remote access to enroll.
