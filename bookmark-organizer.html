    How this works

    Browser bookmark exports are a standard HTML file format that every major browser can both write and read. This tool parses that file, flags entries that share the exact same URL as duplicates, and lets you remove anything you don't want — then rebuilds a valid bookmarks file you can import straight back into any browser.

    Privacy

    • Upload: None. The bookmarks file is parsed and edited entirely in your browser.
    • Storage: Nothing is saved — refreshing the page clears everything.
    • This tool does not check whether links are still live; it only organizes what's in the file you import.

    Frequently asked questions

    Will this delete bookmarks directly from my browser?
    No — it only works on the exported file you import. To apply the cleaned-up result, you'll need to import the downloaded file back into your browser afterward (most browsers let you choose to replace or merge on import).

    Does this check if the links still work?
    No, this tool only organizes and de-duplicates what's already in your export — it doesn't visit any of the links, since checking hundreds of live URLs from a browser tab isn't reliable due to cross-site request restrictions.

    Can I use this across different browsers, like exporting from Chrome and importing into Firefox?
    Yes — the bookmarks HTML export format is a shared standard supported by Chrome, Firefox, Edge, and Safari, so a cleaned file exported here should import into any of them.
