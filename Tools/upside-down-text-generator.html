Upside Down Text Generator

Type something and flip it upside down instantly using special Unicode characters — then copy and paste it into a bio, chat, or post. You can also turn flipped text back to normal.

How it works

  1. Each letter is swapped for a Unicode character that looks like it rotated 180° — for example a → ɐ, e → ǝ, and ? → ¿.
  2. The order is reversed too, so the text reads correctly when you turn your head upside down. Multi-line text flips line order as well.
  3. Copy and paste it anywhere that accepts Unicode text — it's real text, not an image.

Flipped text uses uncommon Unicode symbols, so a few characters may show as empty boxes in fonts or apps that don't support them, and screen readers may read it unhelpfully — avoid using it for anything that has to be accessible. Characters with no upside-down equivalent (like most emoji) are left as they are. Nothing you type is uploaded or stored.
