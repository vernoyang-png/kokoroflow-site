Pixels needed for a print

DPI vs pixels

Changing a DPI label alone does not create detail. Print quality depends mainly on pixel dimensions divided by print size. This calculator uses pixels per inch, commonly called DPI in print workflows.

Quick guide

  • 300 PPI: high-quality close viewing
  • 150 PPI: posters and larger prints
  • 72 PPI: screen reference, usually low for print

Understanding print size and image detail

The calculation

Printable width in inches equals pixel width divided by pixels per inch. A 3,000-pixel image prints 10 inches wide at 300 PPI. Selecting centimetres changes only the displayed physical unit.

The optional image picker reads pixel dimensions locally; it does not upload or enlarge the file.

Avoid a common DPI mistake

Changing a DPI label does not create detail. Enlarging a small image requires invented pixels and may still look soft. Viewing distance, paper, printer, sharpening, and original focus also affect quality.

Ask your printer about pixel dimensions, colour profile, bleed, and file format.
