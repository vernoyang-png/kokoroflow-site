How this works

Each mode builds the correctly-formatted data a QR scanner expects — a wa.me link for WhatsApp, a line.me link for LINE, a t.me link for Telegram, or a standard vCard block for contact cards — then renders it as a QR code entirely in your browser.

Frequently asked questions

Does the LINE QR code work the same as the one in the LINE app?
It uses LINE's standard add-friend link format, so scanning it with a phone camera or the LINE in-app scanner opens the same add-friend screen as LINE's own QR code. Your LINE ID must be set to allow adding by ID for this to work.

Will the WhatsApp QR code work without saving my number first?
Yes — WhatsApp's wa.me links open a chat with that number even if it isn't saved as a contact, which is exactly why this format is commonly used for business cards and event signage.

What is a vCard, and why would I use it instead of a plain text QR code?
A vCard is a standard contact-card format. When a phone scans a vCard QR code, it offers to save the details directly as a new contact — name, phone, email, and all — instead of just showing plain text you'd have to type in manually.

Can I print the downloaded QR code?
Yes, the download is a PNG image suitable for printing on business cards, posters, or table signage. For small print sizes, keep the encoded text short — longer text creates a denser, harder-to-scan pattern.
