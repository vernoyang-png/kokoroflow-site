How this works

Browsers don't allow a webpage to directly rename files sitting on your computer — that's a deliberate security limit, not a bug. Instead, this tool reads each selected file, applies your renaming rule, and packages everything into a single ZIP file with the new names already applied, ready to extract wherever you like.

Privacy

  • Upload: None. Files are read and repackaged entirely in your browser.
  • Storage: Nothing is kept after you leave the page.
  • Limits: Very large batches (hundreds of high-resolution files) may take a moment to zip since it all happens on your device.

Frequently asked questions

Does this actually rename the files on my computer?
Not directly — for security reasons, browsers can't modify files sitting on your hard drive. Instead, this tool creates copies with the new names inside a downloadable ZIP, which you can then extract to replace or supplement your originals.

What happens if two files end up with the same new name?
The preview table lets you check every result before downloading. If a rule like find-and-replace produces a collision, you'll see two identical names in the preview — try adjusting the rule, or switch to sequential numbering, which never produces duplicates.

Does sequential numbering keep the original file extensions?
Yes — only the name portion is replaced with the base name and number; each file's original extension (.jpg, .pdf, .docx, etc.) is preserved automatically.
